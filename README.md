CSS (Cascading Style Sheets) is a language used to design and style web pages. It controls the appearance of HTML elements such as colors, fonts, backgrounds
Types of CSS:-
There are three main types of CSS:
1. Inline CSS
Inline CSS is written directly inside an HTML element using the style
2. Internal CSS
Internal CSS is written inside the <style> tag in the <head> section of an HTML document.
3. External CSS
External CSS is written in a separate .css file and linked to the HTML document.
Typography:-
Typography is the way text is designed and displayed on a webpage. It includes the font, size, color, spacing, and style of text.
Common CSS typography properties are:
font-family – changes the font
font-size – changes text size
font-weight – makes text bold or light
color – changes text color
text-align – aligns the text
line-height – controls space between lines
CSS Selectors:-
CSS selectors are used to select HTML elements and apply styles to them.
Common selectors:
Element Selector: p
Class Selector: .box
ID Selector: #header
Universal Selector: *
Cascade:-
Cascade means CSS decides which style should be applied when multiple styles are given to the same element.
Inheritance:-
Some CSS properties are automatically passed from a parent element to its children.
CSS Box Model:-
Every HTML element is treated like a box.
The CSS Box Model has four parts:
Content → Actual text or content
Padding → Space inside the box
Border → Line around the box
Margin → Space outside the box
Typography, Colours & Units:-
Typography:-
Typography means styling text.
It controls:
Font style
Font size
Font weight
Text alignment
Colours:-
CSS is used to change colors.
Units:-
Units are used to define sizes.
Examples:
px → Pixels
% → Percentage
rem → Relative unit
Flexbox:-
Flexbox is used to arrange items in a row or column.
Basic CSS Grid:-
CSS Grid is used to create layouts with rows and columns.
Responsive Layouts:-
A responsive layout means the website adjusts properly to different screen sizes.
Media Queries:-
Media Queries are used to apply different CSS styles for different screen sizes.
